# Contributing to The ELSA Way

Thank you for helping build The ELSA Way! Anyone can contribute, inside or outside the ELSA AI Lab.

Every contribution follows the same path:

1. **Open an issue** with one of the [issue forms](https://github.com/the-elsa-way/the-elsa-way/issues/new/choose): report an error, suggest content, report a site problem, or ask a question. Declare any conflict of interest in the issue.
2. **An editor triages it**: the issue is accepted (with a review level), gets a question back, or is closed with an explanation.
3. **Pick up an accepted issue**: comment that you would like to work on it, and an editor assigns it to you.
4. **Make the change** in a fork (or a branch, if you are a repository member), or use the edit button on any page of the website.
5. **Open a pull request** against `main` that says `Closes #<issue number>`. Typos and broken links can skip the issue: tick "This is a small fix" in the pull request form.
6. **Review and merge**: the checks build the book and confirm the issue link; editors review according to the review level and merge.

The full guide, including labels and review levels, is in the book:

- [Contributing to The ELSA Way](https://the-elsa-way.github.io/the-elsa-way/contributing) for contributors
- [Triage and review](https://the-elsa-way.github.io/the-elsa-way/triage-review) for editors
- [Style guide](https://the-elsa-way.github.io/the-elsa-way/style-guide), [Governance](https://the-elsa-way.github.io/the-elsa-way/governance) and [Code of conduct](https://the-elsa-way.github.io/the-elsa-way/code-of-conduct)

Add your name to the [Contributors](https://the-elsa-way.github.io/the-elsa-way/contributors) page (`website/community-handbook/contributors.md`) in the same pull request as your contribution.
