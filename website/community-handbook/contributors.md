# Contributors

Everyone who contributes to The ELSA Way is listed on this page, whether they fixed a typo, wrote a chapter, reviewed a pull request or shared a patient perspective in an issue.

GitHub also keeps an automatic record of everyone whose commits are in the repository: see the [contributor graph](https://github.com/the-elsa-way/the-elsa-way/graphs/contributors). That graph misses people who contributed without writing code or text themselves, such as reviewers and people who took part through an issue or a workshop. This list includes them.

## How to add yourself

Add your name in the same pull request as your contribution. Put it at the end of the list below, as one line in this format:

```markdown
- Your Name (optional: role or organisation)
```

If you contributed without a pull request, for example by reviewing or through an issue, ask an editor to add you, or open a small pull request that only adds your name. If you prefer not to be listed, leave your name out.
