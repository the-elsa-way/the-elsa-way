# How to use this resource

The book follows the four phases of the AI lifecycle: design, development, evaluation and deployment. You can start at whichever phase your project is in.

## If you are starting a new AI project

Start with [Design](../design/design.md). The decisions made there are the hardest to change later: who will use the system, which problem it solves, which data you need and which ethical and legal reviews apply.

## If you are building the model

Go to [Development](../development/development.md) for data management, privacy, fairness in training data and the design of how clinicians work with the tool. The [FUTURE-AI principles](../future-ai/future-ai.md) section groups all 30 FUTURE-AI recommendations by principle instead of by phase.

## If you are preparing for clinical validation

[Evaluation](../evaluation/evaluation.md) covers how to plan an evaluation, validate at other sites, check fairness across patient groups and report results with guidelines such as TRIPOD+AI {cite}`tripodai2024` and CLAIM {cite}`claim2020`.

## If you are deploying or running an AI system

[Deployment](../deployment/deployment.md) covers integration into clinical work, quality control, monitoring, logging, regulatory compliance and governance over time.

## If you are looking for a practical tool

The [Toolbox](#toolbox) collects workshop methods, games, impact assessments, reporting guidelines and software libraries, sorted by lifecycle phase and FUTURE-AI principle. In the chapters, a **Tools for this step** box points to the tools for that section.

## If you are new to responsible AI

The [Pathways](../pathways/pathways.md) section suggests a route through the book for your role.

## Conventions used in this book

:::

:::

:::{warning}

:::

:::

:class: tip

:::
