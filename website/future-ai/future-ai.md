# FUTURE-AI principles

FUTURE-AI is an international consensus guideline for trustworthy AI in healthcare, agreed by 117 experts from 50 countries over 24 months {cite}`lekadir2025futureai`. It groups 30 recommendations under six principles, whose initials spell FUTURE, plus seven general recommendations. This section gives one page per principle, so you can work on a single principle across the whole lifecycle.

| Principle | What it asks for |
|---|---|
| [Fairness](fairness.md) | The tool performs as well for one group of patients as for another |
| [Universality](universality.md) | The tool works outside the place where it was built: new patients, users and sites |
| [Traceability](traceability.md) | You can follow and account for the tool's history, from development to daily use |
| [Usability](usability.md) | Clinicians and patients can use the tool safely and efficiently, and it helps them |
| [Robustness](robustness.md) | Performance holds when the input data vary in expected and unexpected ways |
| [Explainability](explainability.md) | The tool gives clinically meaningful information about how it reached its output |

The [general recommendations](general-recommendations.md) cover stakeholders, privacy, risks, evaluation, regulation, ethics and societal impact.

For all 30 recommendations in one table, with compliance levels and the chapter that covers each one, see the [FUTURE-AI overview](overview.md). If you prefer to work phase by phase, the Design, Development, Evaluation and Deployment chapters each open with a FUTURE-AI box naming the recommendations they support.
